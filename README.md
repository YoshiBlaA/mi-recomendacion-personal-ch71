# Mini sitio web generado con apoyo de IA

## Pienso
- ¿Qué voy a recomendar?
    - Respuesta: Series del género Anime.
- ¿A quién va dirigida la página?
    - A cualquier persona, habrá tanto series para niños como para un público mayor.
    - Ya que aún no se ha visto cómo manipular el DOM, por ahora se mostrará todo el catálogo de series, pero se propone un futuro filtro una vez que se vea la manipulación del DOM para poder ocultar catálogo no apto dependiendo de la persona que vaya a visitar la página.
- ¿Qué información tendrá cada recomendación?
    - Título
    - Descripción.
    - Enlaces a plataformas donde se pueda visualizar la serie recomendada.
    - ```Aún trabajando en esta parte, espere...```

- ¿Qué quiero que suceda cuando el usuario interactúe con mi página?
    - Mostrar el número de series recomendadas disponibles.
    - Poder entrar a cada página para visualizar la información o poder verla mediante clicks en la misma tarjeta de recomendación.
    - ```Aún trabajando en esta parte, espere...```
